## 一、系统定位

### 1.1 目标
**输入**: "行业标签 + 核心变量" → **输出**: 自动生成实时定价模型

### 1.2 框架定位
把"行业洞察"转化为"算法"：
- **通用框架 (common/)**: 所有标的共用
- **行业插件 (plugins/)**: 按业务逻辑类型挂载公式
- **标的目录 (stocks/)**: 每个标的配置 + 数据 + 调用框架

## 四、插件可扩展性设计

### 4.1 核心原则

**插件按业务逻辑类型划分，不按股票划分。**

同一插件类型可被多个标的共用，区别仅在于config.yaml中的参数：

```
ManufacturingPlugin 共用:
  云南锗业: 售价=锗价, 原料成本=锗矿采购价
  北方稀土: 售价=稀土镨钕价格, 原料成本=稀土矿成本
  赣锋锂业: 售价=碳酸锂价格, 原料成本=锂辉石成本
```

### 4.2 新标的接入路径（零代码修改）

```
1. 复制 stocks/template/ → stocks/新股票代码/
2. 修改 config.yaml（插件类型 + 参数映射）
3. 跑 model.py
```

### 4.3 何时需要新插件？

| 标的 | 业务逻辑 | 现有插件 | 判定 |
|:---|:---|:---|:---|
| 云南锗业锗锭 | 产能×良率×(售价-成本) | ManufacturingPlugin ✅ | 复用 |
| 宁德时代 | 加工费模式 | ManufacturingPlugin ❌ | 需TollPlugin |
| 商业银行 | PB/ROE驱动 | BankingPlugin ❌ | 需新插件 |

### 4.4 插件类型总览

| 插件 | 业务逻辑 | 适用场景 |
|:---|:---|:---|
| ManufacturingPlugin | `产能×良率×(售价-成本)` | 金属冶炼、化工、晶圆 |
| FablessPlugin | `Pipeline×成功率×渗透率×认证因子` | 半导体设计、创新药 |
| PlatformPlugin | `用户基数×ARPU×(1-流失率)` | SaaS、社交、游戏、电商 |
| TollPlugin | `加工费×产能-固定成本` | 电池OEM（待实现） |
| BankingPlugin | `PB×净资产` / 内含价值 | 银行/保险（接口预置） |
| NAVPlugin | `土地储备×单价-负债` | 房地产（接口预置） |

## 六、行业驱动插件

### ManufacturingPlugin (制造与材料)
- 公式: `利润 = 产能 × 良率 × 稼动率 × (售价 - 原料成本)`
- 适用: 金属冶炼、化工、云南锗业锗锭

### FablessPlugin (研发与设计)
- 公式: `营收 = 订单管道 × 研发成功率 × 终端渗透率 × 认证因子`
- 适用: 半导体设计、云南锗业1.6T

### PlatformPlugin (平台与流量)
- 公式: `营收 = 用户基数 × ARPU × (1 - 流失率)`
- 适用: SaaS、社交、游戏、电商

## 七、动态概率与折现引擎

### 7.1 DCF引擎 (Phase 2)

```
企业价值 = Σ [ FCF_t / (1+WACC)^t ] + 终值 / (1+WACC)^n
股权价值 = 企业价值 - 净债务
目标价 = 股权价值 / 总股本
```

⚠️ WACC参数来源:
- 无风险利率: 10年国债(实时)
- Beta: wind历史beta（每季度更新，加过期警告: 超90天未更新则提示）
- 市场风险溢价: 5%

⚠️ Terminal Growth (永续增长率):
- 当前假设3%，注明为假设条件，提供2%/4%敏感性对照

### 7.2 概率加权引擎 (Phase 2)
- 公式: 调整后估值 = 基础估值 × ∏(1 + (magnitude-1) × probability)
- 示例: "1.6T认证通过" 概率65%，影响1.4x

### 7.3 蒙特卡洛 ⚠️ 暂不实现 (Phase 4)
原因: 变量为主观估计，非真实概率分布，快照模式是行业标准

## 十一、关键设计决策

| 决策点 | 选择 | 理由 |
|:---|:---|:---|
| 数据源 | akshare为主 | 免费、无API key |
| 商品价格 | SMM+Playwright | Cloudflare阻挡curl |
| 插件接口 | 抽象基类 | 新行业只需实现compute() |
| 配置文件 | YAML | 人类可读、版本控制 |
| 蒙特卡洛 | 暂不实现 | 变量无真实概率分布 |
| 插件扩展 | 按业务类型非按股票 | 同一插件可复用多个标的 |
| 数据降级 | 4层降级 | 同→东→手动→报错 |
| WACC Beta | 固定+过期警告 | 当前阶段可容忍，动态拉取过度设计 |
